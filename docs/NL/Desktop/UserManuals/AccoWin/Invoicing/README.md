# Desktop - AccoWin - Facturatie

## 1. Inleiding

Met de facturatiemodule maakt u alle verkoopdocumenten voor uw klanten: offertes, verkooporders, leveringen en facturen, plus abonnementen voor terugkerende facturen. De documenten volgen elkaar op in een logische flow:

1. **Verkoopsofferte**: een aanbod aan de klant.
2. **Verkoopsorder**: de bevestigde order van de klant.
3. **Verkoopslevering**: de levering van de goederen (of de retour).
4. **Verkoopsfactuur**: de factuur, meteen geboekt in het verkoopdagboek.

Elk document neemt u over in het volgende type, zodat u geen gegevens opnieuw hoeft in te geven. Een gesloten verkoopsfactuur wordt geboekt in het verkoopdagboek (zie [Dagboeken](../Accounting/Journals/README.md)).

## 2. Onderdelen

- [Artikels](Articles/README.md): artikelen en artikelgroepen beheren.
- [Verkoopdocumenten](SalesDocuments/README.md): offertes, orders, leveringen en facturen maken, omzetten, afdrukken en genereren.
- [Abonnementen](Subscriptions/README.md): terugkerende facturen voor onderhoudscontracten en dergelijke.

## 3. Vooraf

- De module vereist de licentie **Verkoopsmodule**.
- Via **Parameters > Scherm opties** stelt u op de tab **Verkoopsfactuur** de standaardinstellingen in, onder andere het type **betaalreferentie** (meestal een gestructureerde mededeling). Vermeldt de klant die referentie bij zijn betaling, dan wordt de factuur bij het inlezen van het CODA-bestand automatisch afgepunt (zie [Coda](../Coda/README.md)).
- De factuurlayout die u selecteert op de klantfiche bepaalt het uitzicht van de afgedrukte documenten.
