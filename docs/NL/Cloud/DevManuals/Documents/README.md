# Voorbereiding

Organization Vat Number zetten op een geregistreerd bedrijf op scrada testomgeving.
Neem bij voorkeur 0662348959 (als deze nog vrij is). Dan heb je meteen een test vat nr. voor Scrada en de Fod Applicatie.
Organizatie Plan Type "Free" gaat niet werken, dus hoger.
