# LBRP Cloud - Identity - Invoices

## 1. Invoices

On the **Invoices** tab you can view and manage your monthly cost overview:

1. **Monthly invoices**
   - Every month, an invoice is automatically generated based on the usage of the activated applications.

2. **Viewing details**
   - Click on an invoice to view the specifications, including the usage and costs per application.

3. **Paying an invoice**
   - Easily pay the outstanding invoice via the available payment methods (**Stripe** or **PayPal**).

This tab provides a clear overview of your expenses and makes it easy to keep track of payments.
