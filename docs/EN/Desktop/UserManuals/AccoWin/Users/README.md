# Desktop - AccoWin - Users and rights

## 1. Introduction

Every employee logs on to **AccoWin** with his own **logon name** and **password**. Per user you decide whether he is active, to which company he belongs and in which dossiers he may work. The functions are in the **Start** menu:

- **Gebruikers** (Users): manage the users;
- **Toewijzen Gebruiker-Dossier** (Assign user-dossier): link users to dossiers;
- **Verander paswoord** (Change password): change your own password;
- **Afloggen** (Logoff): log off so a colleague can log on.

## 2. The user record

Via **Start > Gebruikers** you open the user file. The list shows per user the **logon name**, the **Windows logon name**, the **e-mail address**, the **company** and the **name**, plus flags for **superuser** and **active**. On the record you enter:

- the **name** and **reference** of the user;
- the **AccoWin logon name** and the **Windows logon name** (for automatic recognition of the Windows session);
- the **password** — with **Nieuw paswoord** (New password) you set a new one;
- the **company** the user belongs to and his **e-mail address**;
- **active**: whether the user may log on.

Superusers may do everything; normal users only see the dossiers assigned to them.

## 3. Assign user-dossier

With **Start > Toewijzen Gebruiker-Dossier** you decide which user works in which dossier. Link every employee to his dossiers; a user without an assignment cannot open a dossier. The same link holds for the office functions (such as [dossier management](../BackupDatabase/README.md)).

## 4. Changing the password

With **Start > Verander paswoord** you change your own password: enter the old and the new password. The administrator sets a password for a colleague via the user record (**Nieuw paswoord**).

## 5. Logging off

**Start > Afloggen** logs you off without closing **AccoWin**: the next user logs on with his own logon name and immediately sees his own dossiers.

## 6. Tips

- Give every employee his own logon name; that way the history shows who did which booking or mutation.
- Change passwords regularly and do not use shared accounts.
- Deactivate a user with **active** instead of deleting him: the history stays intact.
