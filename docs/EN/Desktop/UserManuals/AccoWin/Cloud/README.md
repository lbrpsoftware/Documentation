# Desktop - AccoWin - Cloud connection

## 1. Introduction

**AccoWin** connects to the **LBRP Cloud Platform** for the licence and the cloud services, such as [importing UBL documents and CODA files from the cloud](../UBL/CloudImport/README.md). You register the connection once; afterwards **AccoWin** checks the licence automatically via the cloud.

## 2. Logging on via the licence

1. Choose **About > Licentie** (Licence). The logon screen of the LBRP Cloud opens.
2. Register your cloud account (or log on with your existing account) and link this **AccoWin** installation to it.
3. After the successful connection **AccoWin** works with the options granted to your account; licence changes are seen after a restart of the program.

## 4. Enabling or disabling applications

In the cloud portal you decide which applications are active for your organisation (see the second video). Enable **AccoWin** for every workstation that works with it; a disabled application cannot log on.

## 5. Tips

- Do the registration once per installation.
- The cloud functions (UBL and CODA import) use the same account: you do not have to log on twice.
- With logon problems first check whether the application is enabled in the cloud portal.
