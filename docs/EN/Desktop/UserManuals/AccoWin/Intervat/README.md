# Desktop - AccoWin - Intervat

## 1. Introduction

With the new version of AccoWin, version 1.2.0.5, it is possible to submit VAT returns electronically via Intervat. This manual shows you step by step how you can use this AccoWin application. 2. Creating a VAT return of a dossier

## 2. Creating a VAT return of a dossier

The procedure to create a VAT return of a dossier remains unchanged in the new version of AccoWin. You create a VAT return of a certain period for a certain dossier as follows:

- Start AccoWin
- Select dossier in AccoWin
- In menu: select Reports > VAT > VAT return

![Image 1]()

- Afterwards you see the screen of the VAT return. You select the VAT period for which you want to create the return and you fill in the other details such as paid advances, balance still to be received... <br/>
  At the bottom of the screen you see when the return was submitted and via which channel. If you create a completely new VAT return, this field is still blank.

![Image 2]()

- By clicking the 'Start print' button, the VAT return is created and can be forwarded via Intervat.
- You can forward several VAT returns at the same time via Intervat. It is therefore perfectly possible to create the returns and submit them at the end of the VAT period via Intervat.

## 3. Preparing the file

- In the main menu of AccoWin you click on 'Intervat' > 'Submit VAT returns'. The application will start automatically, regardless of the dossier you have open at that moment.

![Image 3]()

### _3.1 Basic details_

- A screen appears on which you must fill in a number of basic details:

  - <ins>Submitter</ins>: These are the personal details and the VAT number of the person who will submit the VAT returns.
  - <ins>Period</ins>: Here you must select the year, the month and/or the quarter of the VAT returns you want to submit. The program automatically fills in the details of the previous period here. For example, in January 2008 AccoWin will automatically select '2007' as the year, 'December' as the month and '4th quarter' as the quarter.
  - <ins>File</ins>: Here you can adjust the location where you want to save the file. You also see the unique reference that AccoWin will use for the file. This unique reference cannot be changed.

![Image 4]()

- After filling in the basic details, click the button <!-- ![Image 5]() -->. AccoWin will then generate all dossiers with returns for the selected period. This process can take a while. In the time bar at the bottom of the screen you can follow the progress of this search.

### _3.2 Selecting returns_

- After all dossiers have been processed, the following screen is displayed:

![Image 6]()

- This screen consists of 3 parts:
  - <ins>Errors and/or already sent VAT returns</ins>: Here you see all VAT returns that are not included to be forwarded via Intervat. By default, the returns that have already been forwarded or that contain an error end up here.
  - <ins>Selected VAT returns to send</ins>: Here are all returns that can be forwarded.
  - <ins>Dossiers that have no VAT return</ins>: Dossiers for which no VAT return has been created yet are visible in this list. That way you can also always check whether any dossiers have been forgotten.
- Returns can be moved from the selected returns to the non-selected returns by using the buttons ![Image 7]() and ![Image 8]():
  - Button ![Image 9]() moves the selected return from right to left. A selected return can thus be moved to the non-selected returns.
  - Button ![Image 10]() moves the selected return from left to right. A non-selected return can thus be moved to the selected returns.

**If a return contains errors, AccoWin will stop the move from the non-selected returns to the selected returns. The return can only be moved once the errors have been corrected**.

- With the selected returns, the amount to be paid or the credit of the return is always displayed. You can also see whether there is a request for refund (column 'T') and/or a request for transfer forms (column 'O').
- By turning on the option 'Show sent VAT returns' you can see the VAT returns for which an Intervat file has already been generated.
- By clicking the button ![Image 11]() the file can be created.

### _3.3 Creating the file_

- After selecting the files and pressing the 'Next' button, you arrive at the following screen:

![Image 12]()

- Click 'Press here to generate file' to generate the file with the electronic VAT returns that are ready for submission via Intervat. Creating this file can take a while.
- AccoWin then indicates that the file has been generated:

![Image 13]()

If the file has exceptionally not been generated, click the 'Press here to generate file' button again.

- The screen shows where you can find the file.

![Image 14]()

- You press the 'Copy file location' button. This saves the file name in the memory. You will need this file name again on the Intervat website.
- You can print the generated file in a nice layout by clicking 'Print generated file'.
- Via the 'Open Intervat Website' button you go directly to the Intervat website.

## 4. Submitting a return via Intervat

### _4.1 Going to the Intervat website_

- By clicking the 'Open Intervat Website' button in AccoWin, you arrive at the Intervat website.

![Image 15]()

- Press the button ![Image 16]() to continue.

### _4.2 Signing in_

- Then you arrive at the following page:

![Image 17]()

- Here you can choose to sign in via electronic identity card or via a certificate from Isabel, GlobalSign or Certipost. We advise you to sign in via electronic identity card. Click on 'Authentication via electronic identity card'.
- In the next screen you will be asked to insert your identity card into the card reader:

![Image 18]()

- You insert your identity card into the card reader and press the 'LOGIN' button.
- Next, you must select a certificate. This is the certificate with your name that ends in ('Authentication'). Press 'OK' to continue.

![Image 19]()

- Afterwards your PIN code is requested. Please enter it and press OK:

![Image 20]()

### 4.3 Selecting the file

- You are now logged in to the Intervat website and see the following screen:

![Image 21]()

- On the left of the screen you first indicate 'Return(s) via XML file' and then 'New':

<!-- |               |               | -->
<!-- | :-----------: | :-----------: | -->

| ![Image 22]() | ![Image 23]() |

- You arrive at the following screen:

![Image 24]()

- Here you fill in the file name. This can be done in 2 ways:
  - Click on the field next to 'Location' and press 'CTRL+V' there. The file name is then automatically taken from the memory of your PC (clipboard).
  - Click the 'Select' button and look up the file.

### _4.4 Validating the file_

- Once the file is selected, press 'Validate' and then 'Next'.

![Image 25]()

### _4.5 Signing the file_

- The screen below appears. Fill in the requested details and click 'Send'.

![Image 26]()

### _4.6 Confirming to forward or cancel_

- The system asks for a final confirmation before sending the return. Press 'Confirm' for this.
- Sending the return can take some time. Please wait until you receive the confirmation that the return has been sent.

![Image 27]()

### _4.7 Downloading the receipt in PDF format or XML format_

- Once the return has been sent, you can download the receipt in PDF format or in XML format.
- Indicate the format of your choice and download the receipt. You can open it and print it on your printer. You can also save the receipt on your PC.

![Image 28]()

You have now reached the end of the application. Press 'Back to the main page' to return to the Intervat start page.
