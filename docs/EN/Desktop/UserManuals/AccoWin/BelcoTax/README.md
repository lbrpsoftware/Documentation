## 2. Automatically creating records 281.50 from the booked purchase invoices:

### 2.1 General ledger account

The records 281.50 can be created if these costs have been booked via a purchase invoice. The details of the beneficiary are in the supplier records (name, address, place of residence, CBE number, National Number, natural person/legal person.

Before records can be forwarded, a number of changes must be made in the supplier records and the general ledger accounts of Accowin.

On the general ledger account, one indicates that a record 281.50 must be created for these purchase invoices. A distinction is made between commissions/fees/benefits/costs for the account of the acquirer. This means that a separate general ledger account must be created per type.

![Image 3](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172208/original/Aggg5QNXwbQQEOwFvKKWdJqOgTAca_wZ0g.png?1654073533)

### 2.2 Supplier record:

Name + first name of the beneficiary, address + place of residence

Enterprise number: to be filled in in the field of the VAT number (BE only if VAT liable)

Nature of record 281.50: if the recipient of the remunerations is a sports practitioner, trainer or instructor, this can be specified here. The remunerations are then additionally included under the codes 2.066 or 2.067

Nature: natural person or legal person.

For a legal person, the enterprise number must always be filled in in the VAT number field.

For a natural person: fill in the National number. If the National number is not known, this can be solved by placing a comma between the Name and the First name so that these details are separated in the return.

**Country code**: important for retrieving the NSSO number of that country. For Belgium this is 0000. Every other country has its own NSSO code that is adopted in the return.

### 2.3 Generating records 281.50

Select the menu Belcotax-Generate records 281.50 to start creating the records.

![Image 4](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172203/original/145ZKBRcWB6Z1xWguKoPRGAiMfAAAqfISQ.png?1654073533)

After selecting the menu choice, Accowin shows an overview of all dossiers that are not in order for creating the records 281.50. If records 281.50 still need to be made for these dossiers, then these dossiers must be selected one by one so that Accowin can update these dossiers.

![Image 5](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172199/original/2bGihkQOLt3mZyu8zHsgFh2x14vmyvmlww.png?1654073533)

By choosing Print, this list can be printed to do further processing. <br/> <br/>

After printing or Close, Accowin asks to remove these dossiers from the overview list. Answer Yes if you want to continue working without taking these dossiers into account.

![Image 6](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172204/original/F-efceYlKDRXnkeAV6NXdlTAUwmU6xckXg.png?1654073533)

Select the dossiers for which records 281.50 should be created.

With <img src="https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172197/original/bsXEUBxSisLVtVkTJMbEG2QK0R1M0ovhzQ.png?1654073533" alt="image 8" height="16"> the selection can be undone.

![Image 9](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172210/original/iEbEgS-ejGfTx79UKlYhI51uqh7Y5cf2xw.png?1654073533)

With the selection button **_CREATE RECORDS_** accowin generates the records of all dossiers for which fee records need to be created.

_Tip: It is recommended to create the records 281.50 dossier by dossier_. <br/>
_This way you keep a better overview and can intervene better if details of the beneficiary are missing_.

If the program notices incorrect data when creating the records, an overview with the found errors is shown after creating the records. The list can be printed to make the necessary adjustments to the data. <br/>
(on the supplier records or at the dossier details)

After clicking CREATE RECORDS, accowin shows an overview with the generated records.

![Image 10](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172214/original/yH23seTiKKPTmpl0cyItxEJN5FOmoe3dQA.png?1654073533)

Click on **_Return detail_** to consult the details of the declarant. <br/>

Click on **_Overview purchase invoices_** to see the list of the purchase invoices that were taken into account to compose the selected record.

![Image 11](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172209/original/vvzgS0hzQ7AyKEym7MM2XSp8AFT-4z2l2w.png?1654073533)

Via the button **_print checklist_** an overview of the records with the associated purchase invoices can be printed

![Image 12](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172205/original/98qIFexG_TfyS2MuP7KK0DA_hR2nxBEWfA.png?1654073533)

If all records are complete, and no data is missing, the records can be definitively transferred to the dossiers via the button **_Transfer records to dossiers_**.

Once the generated records have been adopted in the dossiers, they can be consulted and modified as with the manual entry of records.

## 4. Creating and sending the XML file to Belcotax.

Select the menu **_Belcotax – Create XML_**.

You get a selection list with the dossiers for which records exist that can be forwarded via Belcotax.

![Image 14](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172213/original/sEn9Gj5tDChRvJxDN4wj3tbDYThHSrjerw.png?1654073533)

There are 2 types of XML file that can be created:

XML for **definitive** return or XML for **test return**. <br/>

_Tip: first create a test file to send to Belcotax; with this you can check whether all data in the file is correctly processed by Belcotax. If no errors are reported by Belcotax when processing the test file, a definitive return can be forwarded_. <br/>

Select the dossiers that should be included in the XML file that you want to send via Belcotax and press the OK button.

Next, the screen is shown to start the BELCOTAX application. By clicking on **_Copy file location_** you can place the location in the memory to paste it afterwards.

![Image 15](https://s3-eu-central-1.amazonaws.com/euc-cdn.freshdesk.com/data/helpdesk/attachments/production/101015172212/original/Bgeedbf-NRQQOwMoi_ajorzjQ3JCvFsXVA.png?1654073533)
