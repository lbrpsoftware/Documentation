# Desktop - AccoWin - Flat rates (Forfaits)

## 1. Introduction

For entrepreneurs under a flat-rate (forfaitair) regime (baker, butcher, café, hairdresser, fry shop and the general flat rate) **Accowin** calculates the flat-rate profit and the VAT on the basis of parameters instead of the actual bookings. The functions are in the **Forfaits** menu:

- **Alle Forfaits** (All flat rates): management of all flat rates (mainly for the management of the office and licence data).
- **Parameters Forfait** (Flat rate parameters): set the flat-rate parameters per dossier.
- **Berekenen Forfait** (Calculate flat rate): run the flat-rate calculation.
- **Overzicht café** (Café overview): the specific overview for the **grand café** flat rate (only visible when the dossier contains this flat rate).
- **BTW Forfait - Fisconet**: consult and use the official flat rates and percentages from Fisconet.

**Rights**: for **Parameters Forfait** your user needs the right **Forfait parameters**, and for **Berekenen Forfait** and the overviews the right **Forfait print**. The menu item **Berekenen Forfait** is only available when flat-rate codes are set.

## 2. Setting up a flat rate

1. Make sure the dossier uses the right flat-rate type: baker, butcher, grand or small café, hairdresser, fry shop or general. For a general flat rate you create it via the screen **Nieuw algemeen forfait** (New general flat rate): enter a **new reference** and click **Aanmaken** (Create).
2. Choose **Forfaits > Parameters Forfait** and fill in the flat-rate base data of the type, among others the turnover thresholds and percentages per regime.
3. Retrieve the current percentages via **Forfaits > BTW Forfait - Fisconet** so the calculation works with the official figures of Fisconet.

## 3. Calculating the flat rate

1. First book all transactions of the financial year that go into the flat-rate calculation (purchases, staff costs and similar, following the rules of the regime).
2. Choose **Forfaits > Berekenen Forfait**.
3. **Accowin** calculates the flat-rate profit and the matching VAT following the parameters, and shows the result for checking before booking.
4. Check the result, adjust the parameters if needed and run the calculation again.

## 4. Café overview

For dossiers with a **grand café** flat rate you print the specific café overview via **Forfaits > Overzicht café**: the components of the flat rate (drinks, food, staff) with the applied percentages.

## 5. Cooperation with the bookkeeping

- The flat-rate calculation uses the bookings of the dossier: the [journals](../Accounting/Journals/README.md) remain the basis.
- The results of the flat-rate calculation influence the [VAT return](../Vat/README.md) and the [reports](../Reports/README.md) of the dossier.
- Before the [year-end closing](../YearEnd/README.md) run the flat-rate calculation definitively, so the flat-rate figures are processed in the balance sheet.

## 6. Tips

- The official flat rates and percentages change regularly: renew them via **BTW Forfait - Fisconet** before every calculation.
- Keep the right flat-rate type per entrepreneur; the wrong type gives wrong results immediately.
- In doubt about the parameters, compare the outcome of **Berekenen Forfait** with last year's result before you book definitively.
