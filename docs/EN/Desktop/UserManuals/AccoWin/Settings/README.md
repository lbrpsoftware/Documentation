# Desktop - AccoWin - Parameters

## 1. Introduction

The **Parameters** menu contains the settings of **AccoWin** and the links with other programs. Most settings hold for all dossiers; a few you set per dossier under [dossier management](../BackupDatabase/README.md).

## 2. Language and appearance

- **Taal** (Language): switches the user interface (Dutch, English, and so on).
- **Themes**: the colour theme of the program.
- **Dagontvangsten** (Day receipts): the settings for creating day receipts.

## 3. Master files for the bookkeeping

In the **Parameters** menu you further manage:

- **Algemene rekeningen - standaard** (Standard general accounts): the standard chart new dossiers get; with **dossier -&gt; standard** you copy the chart of a dossier to the standard chart;
- **Verkoopsvoorwaarden en extra teksten** (Sales conditions and extra texts): the texts on your sales documents;
- **Betaalwijze** and **Verzendwijze** (Payment and shipping method): the codes you choose on documents and records;
- **Teksten rappels** (Reminder texts): the texts for your [reminders](../Rappels/README.md);
- **Teksten email** (E-mail texts): the e-mail templates (see [E-mail](../Email/README.md) §2);
- **Rapporten** (Reports): the report definitions and templates.

Next you set per dossier the **journals** and **centralisations**, the **currencies and rates** and the **VAT codes** via the master files of the dossier.

## 4. Import

The submenu **Import** contains the [classic imports](../Import/README.md): Excel (articles, customers, suppliers), Cubic Dos, Bob 50, Winbooks and Exact.

## 5. Options

- **Algemene opties** (General options): the main settings of the program: paths, defaults, e-mail settings and similar;
- **Scherm opties** (Screen options): how screens and grids behave (column widths, font size, window position).

## 6. Tips

- With a new installation first check the **general options** before you create dossiers: many default values come from there.
- Keep the **standard chart of accounts** up to date: new dossiers take it over unchanged.
- Changes to texts and payment/shipping methods hold for all dossiers; test them on a test dossier before a production dossier.
