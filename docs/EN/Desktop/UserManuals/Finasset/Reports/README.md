# Desktop - Finasset - Reports

## 1. Introduction

The **Reports** menu contains all prints of **Finasset**. All reports first open the parameters screen **Afdrukken** (Print), in which you choose the range and the content; afterwards the print preview of the report opens.

## 2. The Print parameters screen

In the screen **Afdrukken** you set:

- **Rekening vanaf** and **tem** (Account from / to): the account range of the report;
- **Taal** (Language): the language of the report;
- **Kalenderjaar** (Calendar year): whether the report is built on calendar year or financial year;
- **Afdruk detail** and **Definitief** (Print detail / Final): draft or final version; with **huidige datum afdrukken** you put the date on the print;
- **Toekomstig boekjaar** or **bestaand boekjaar** (Future or existing financial year): for reports that look ahead or back;
- **Toon uitboekingen** (Show disposals): include disposed investments or not;
- with **Select alles** and **Unselect alles** (Select / unselect everything) you turn all (or no) **columns** on in one go: **investment reference**, **description**, **purchase invoice number**, **supplier**, **purchase date**, **disposal date** and more — this way you decide yourself which data appear on the table.

## 3. The reports

| Report | Content |
|---------|--------|
| **Aanwervingen** (Acquisitions) | The investments purchased in the financial year, with purchase value and investment deduction |
| **Afschrijvingstabel** (Depreciation table) | The depreciations per investment and financial year, with percentages and totals |
| **Afschrijvingstabel fiscaal** (Fiscal depreciation table) | The fiscal variant of the table, as justification of the return |
| **Afschrijvingstabel totaallijnen per rekening** (Total lines per account) | The totals per general account, as the bridge to the journal entries |
| **Afschrijvingstabel meerdere jaren** (Multiple years) | The table across several financial years |
| **Jaaroverzicht** (Year overview) | The overview of the financial year: acquisitions, depreciations and disposals together |
| **BedrijfsMiddelen** (Assets) | The table of assets: all investments with their current book value |
| **Toelichting balans** (Balance annotation) | The annotation for the fixed assets balance item, with size criteria |
| **Uitboekingen** (Disposals) | All disposals of the financial year with their result (see [Disposals](../Disposals/README.md)) |
| **Investeringaftrek** (Investment deduction) | The applied investment deduction per investment |
| **Journaalposten** (Journal entries) | The booking files for your accounting program: purchases, depreciations and disposals per account |

## 4. Working with the printout

- In the **print preview** you page through the report before you print or save it as PDF.
- Best print reports in the language of the dossier: the descriptions of accounts and investments follow that language (see [General accounts](../GeneralAccounts/README.md) §2).
- Check the report **Journaalposten** after every [recalculation](../Depreciation/README.md) of the depreciations.

## 5. Tips

- First run a **draft print** (Afdruk detail, not final) to check the range; a final print counts as the version for the dossier.
- Keep the **fiscal depreciation table** and the **balance annotation** of every financial year: they are the standard justification towards the tax office.
- Use the **total lines per account** as a check against the report **Journaalposten**: both totals must match before the bookkeeping is transferred.
