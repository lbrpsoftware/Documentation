# Desktop - Finasset - Cloud connection

## 1. Introduction

**Finasset** connects to the **LBRP Cloud Platform** for the licence and the cloud services (such as MyMinFin and eBox documents via the **Connect** menu). You register the connection once; afterwards **Finasset** checks the licence automatically via the cloud.

## 2. Logging on via the licence

1. Choose **About > License**. The logon screen of the LBRP Cloud opens.
2. Register your cloud account (or log on with your existing account) and link this **Finasset** installation to it.
3. After the connection succeeds, the main window shows the **licence status**. As long as the status is valid, **Finasset** works with the options granted to your account.

## 4. Enabling or disabling applications

In the cloud portal you decide which applications are active for your organisation (see the second video). A disabled application can no longer log on; enable **Finasset** for every workstation that works with it.

## 5. Tips

- Do the registration once per installation; afterwards everything runs automatically at start-up.
- Changes to the licence (extra workstations, modules) are only seen by **Finasset** after a restart of the program.
- With logon problems first check whether the application is enabled in the cloud portal.
