# Desktop - Finasset - Users and rights

## 1. Introduction

**Finasset** is a multi-user program: every employee logs on with his own **logon name** and **password**, and per user you decide what he may do. The management functions are in the **Start** menu:

- **Users**: manage the users;
- **Assign user dossier**: assign users to dossiers;
- **Change password**: change your own password;
- **Logoff**: log off.

## 2. The user record

Via **Start > Users** you open the user record. Per user you record:

- the **logon name** and the **name**;
- the **password** — with the button **Nieuw paswoord** (New password) you set a new password;
- **e-mail** and **telephone**;
- the **Windows logon name**: links the user to his Windows session;
- **Actief** (Active): whether the user may log on;
- **Superuser**: an administrator who may do everything, regardless of the rights below.

Below that you switch the **rights** on or off:

- **Dossiers aanmaken** (Create dossiers): may set up new dossiers;
- **Uitboeking bewerken** (Edit disposal): may carry out [disposals](../Disposals/README.md) — a far-reaching and irreversible action;
- **Standaard alg rek kunnen bewerken** (Edit standard chart): may change the [standard chart of accounts](../GeneralAccounts/README.md) §3, with consequences for all new dossiers.

## 3. Dossier assignment

On the user record, and also via **Start > Assign user dossier**, you assign the users to the dossiers:

- first choose the **user** and the **dossier** in the **selection**;
- in the overview **Dossiers/Gebruikers** (Dossiers/Users) you check the combinations that may have access; with **Alle dossiers geven** (Give all dossiers) the user gets access to everything.

A user only sees the dossiers assigned to him; the superuser sees them all.

## 4. Changing the password

With **Start > Change password** you change your own password: enter the **old password**, then the **new password** twice (**confirm**) and click **Aanpassen** (Apply). Administrators set a new password for another user via the user record.

## 5. Logging off

With **Start > Logoff** you log off without closing the program: the next user logs on with his own logon name. This way you switch users without restarting **Finasset**.

## 6. Tips

- Give every employee his own account; do not work with a shared logon name, because you lose the control over who did which disposal or mutation.
- Only turn on **Uitboeking bewerken** for users who may do disposals; the right holds for all dossiers the user has access to.
- Assign **Superuser** only to the program keeper(s) of the office.
