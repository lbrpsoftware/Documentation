# Desktop - BelcoFin - Meal vouchers (Pluxee)

## 1. Introduction

**Belcofin** can order meal vouchers (maaltijdcheques) for the directors of a declarant at **Pluxee**. You set per declarant that an order is placed, **Belcofin** generates the order file and sends it automatically via the LBRP Cloud to Pluxee.

This requires a licence with the right option; when you do not see the menu item, contact your reseller.

## 2. Settings

### 2.1 On the declarant record

Open the declarant and go to the tab **Loonboekingen** (Payroll bookings). Set **Maaltijdcheques bestellen bij** (Order meal vouchers at) to **Pluxee**. Leave the choice empty when no vouchers are ordered for this declarant.

### 2.2 On the wage record of the director

For every director who receives meal vouchers you record per month on the wage record:

- the **number of meal vouchers**;
- the **face value** per voucher (in euro, between € 1.09 and € 12.00);
- optionally the **employer contribution**.

**Belcofin** uses these data to build the order.

## 3. Ordering meal vouchers

1. Choose **Order meal vouchers** in the menu. The selection screen opens.
2. You only see the declarants for which **Maaltijdcheques bestellen bij** is set to Pluxee.
3. Check the declarants for which you want to create an order and click **OK**.
4. **Belcofin** creates the order file per declarant in the Pluxee format (electronic meal vouchers) and sends all files **automatically** in one go via the LBRP Cloud.
5. In the report you see per declarant whether the cloud accepted the file. The confirmation of the order follows via Pluxee.

One worker gets at most five orders per file: spread large orders over multiple batch orders when needed.

## 4. Processing

- The order stands apart from the fiscal fiches: the value of the meal vouchers is registered on the wage record and goes into the payroll calculation the way you set it up.
- The answers and delivery of Pluxee happen outside **Belcofin**; keep track of the order in your own administration.
- For sending via the cloud you must be logged in to the LBRP Cloud (see [Cloud](../Cloud/README.md)).

## 5. Tips

- Before ordering, check that the **number** and **face value** on the wage records are current; the order uses those data unchanged.
- Order in time: Pluxee applies a lead time between the order and the delivery to the workers.
- One order per declarant per batch suffices; repeated orders for the same month are best combined in one file.
